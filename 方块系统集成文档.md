## 1. 方块系统核心接口

### 1.1 BlockWorld - 统一对外接口

**文件**: [Classes/core/block_world.h](Classes/core/block_world.h:67)

这是玩家系统与方块系统交互的**唯一入口**。

```cpp
class BlockWorld {
public:
    // ==================== 查询接口 ====================

    /**
     * @brief 获取指定方块坐标的方块信息
     *
     * @param layer 方块层类型 (LayerType::BLOCK 或 LayerType::WALL)
     * @param blockPos 方块坐标 (Vec2i)
     * @return BlockHandle 方块状态（包含ID、实体、状态码）
     */
    BlockHandle getBlockAtBlockPos(LayerType layer, const Vec2i& blockPos) const;

    /**
     * @brief 获取指定世界坐标的方块信息
     *
     * @param layer 方块层类型
     * @param worldPos 世界坐标 (cocos2d::Vec2)
     * @return BlockHandle 方块状态
     */
    BlockHandle getBlockAtWorldPos(LayerType layer, const cocos2d::Vec2& worldPos) const;

    // ==================== 挖掘接口 ====================

    /**
     * @brief 尝试挖掘方块（累积挖掘进度）
     *
     * @param layer 方块层类型
     * @param blockPos 方块坐标
     * @param mineFactor 挖掘强度（每次调用增加的进度）
     * @param miner 挖掘者实体（玩家实体）
     * @return bool 是否成功开始/继续挖掘
     *
     * @note 挖掘进度达到100%时方块会被破坏
     */
    bool tryMine(LayerType layer, const Vec2i& blockPos, float mineFactor, entt::entity miner);

    /**
     * @brief 尝试挖掘世界坐标的方块
     */
    bool tryMineAtWorldPos(LayerType layer, const cocos2d::Vec2& worldPos, float mineFactor, entt::entity miner);

    // ==================== 破坏接口 ====================

    /**
     * @brief 直接破坏方块（无需挖掘进度）
     *
     * @param layer 方块层类型
     * @param blockPos 方块坐标
     * @param destroyer 破坏者实体
     * @return bool 是否成功破坏
     *
     * @note 用于爆炸、特殊技能等直接破坏场景
     */
    bool tryDestroy(LayerType layer, const Vec2i& blockPos, entt::entity destroyer);
    bool tryDestroyAtWorldPos(LayerType layer, const cocos2d::Vec2& worldPos, entt::entity destroyer);

    // ==================== 放置接口 ====================

    /**
     * @brief 尝试放置方块
     *
     * @param blockPos 方块坐标
     * @param blockID 方块类型ID
     * @param blockState 方块状态码（默认0）
     * @param placer 放置者实体（玩家实体）
     * @return bool 是否成功放置
     *
     * @note 会自动检查该位置是否可放置
     */
    bool tryPlace(const Vec2i& blockPos, entt::id_type blockID, state blockState, entt::entity placer);
    bool tryPlaceAtWorldPos(const cocos2d::Vec2& worldPos, entt::id_type blockID, state blockState, entt::entity placer);

    // ==================== 交互接口 ====================

    /**
     * @brief 尝试与方块交互（右键交互）
     *
     * @param layer 方块层类型
     * @param blockPos 方块坐标
     * @param interactor 交互者实体（玩家实体）
     * @return bool 是否成功交互
     *
     * @note 用于打开箱子、工作台等交互式方块
     */
    bool tryInteract(LayerType layer, const Vec2i& blockPos, entt::entity interactor);
    bool tryInteractAtWorldPos(LayerType layer, const cocos2d::Vec2& worldPos, entt::entity interactor);

    // ==================== 获取层接口 ====================

    /**
     * @brief 获取指定层的BlockLayer引用
     *
     * @note 如果需要使用坐标转换等工具函数，可以通过此接口获取
     */
    BlockLayer& getLayer(LayerType layer) const;
};
```

## 2. 玩家与方块系统交互流程

### 2.1 交互时序图

```
玩家输入 (左键点击)
    ↓
PlayerInputSystem 检测鼠标位置
    ↓
获取玩家当前装备的工具 (PlayerEquipmentComponent)
    ↓
计算挖掘强度 mineFactor (基于工具类型和属性)
    ↓
调用 BlockWorld::tryMineAtWorldPos(layer, mouseWorldPos, mineFactor, playerEntity)
    ↓
BlockMiningSystem 累积挖掘进度
    ↓
进度达到100% → 方块破坏
    ↓
触发 BlockDestroyEvent
    ↓
掉落物品 → Inventory::addItem(itemId, count)
    ↓
播放玩家动画 (PlayerAnimationComponent::AnimState::PICKAXE)
```

```
玩家输入 (右键点击)
    ↓
检查快捷栏当前选中物品
    ↓
如果是可放置物品 (placeable == true)
    ↓
获取鼠标世界坐标
    ↓
调用 BlockWorld::tryPlaceAtWorldPos(mouseWorldPos, item.tileId, 0, playerEntity)
    ↓
触发 BlockPlacedEvent
    ↓
消耗背包物品 Inventory::removeItem(itemId, 1)
    ↓
播放玩家动画 (PlayerAnimationComponent::AnimState::PLACE)
```

## 4. 代码示例

### 4.1 玩家挖掘方块

**文件**: 在 `PlayerInputSystem` 中添加

```cpp
void PlayerInputSystem::handleMining(entt::registry& registry, BlockWorld& blockWorld, float dt)
{
    auto& input = PlayerInput::getInstance();

    // 检测左键按住
    if (!input.isMousePressed(cocos2d::EventMouse::MouseButton::BUTTON_LEFT)) {
        return;
    }

    // 获取鼠标世界坐标
    cocos2d::Vec2 mouseWorldPos = input.getMouseWorldPosition();

    // 获取玩家实体
    auto playerEntity = GameManager::getInstance()->getPlayerEntity();
    if (playerEntity == entt::null) return;

    // 获取玩家装备
    auto* equipment = registry.try_get<PlayerEquipmentComponent>(playerEntity);
    if (!equipment) return;

    // 获取当前快捷栏选中物品
    auto* hotbar = registry.try_get<PlayerHotbarComponent>(playerEntity);
    if (!hotbar) return;

    int inventoryIndex = hotbar->getCurrentInventoryIndex();
    auto& inventory = Inventory::getInstance();
    auto slot = inventory->getSlots()[inventoryIndex];

    // 计算挖掘强度
    float mineFactor = 1.0f; // 默认徒手挖掘

    if (slot.itemId > 0) {
        auto* itemData = ItemManager::getInstance()->getItemData(slot.itemId);
        if (itemData && itemData->equipType == EquipType::Pickaxe) {
            // 镐子挖掘强度 = 基础值 + 伤害值
            mineFactor = 5.0f + itemData->damage * 0.5f;

            // 播放镐子动画
            auto* anim = registry.try_get<PlayerAnimationComponent>(playerEntity);
            if (anim && anim->currentState != PlayerAnimationComponent::AnimState::PICKAXE) {
                PlayerAnimationSystem::transitionToState(*anim,
                    PlayerAnimationComponent::AnimState::PICKAXE);
            }
        }
    }

    // 调用挖掘接口
    bool success = blockWorld.tryMineAtWorldPos(
        LayerType::BLOCK,
        mouseWorldPos,
        mineFactor * dt,  // 每帧累积进度
        playerEntity
    );

    if (success) {
        CCLOG("Mining block at (%.2f, %.2f) with factor %.2f",
              mouseWorldPos.x, mouseWorldPos.y, mineFactor);
    }
}
```

### 4.2 玩家放置方块

**文件**: 在 `ItemUseSystem` 中扩展

```cpp
bool ItemUseSystem::placeBlock(entt::registry& registry, entt::entity playerEntity,
                               int itemId, cocos2d::Vec2 worldPos)
{
    // 获取物品数据
    auto* itemData = ItemManager::getInstance()->getItemData(itemId);
    if (!itemData || !itemData->placeable) {
        CCLOG("Item %d is not placeable", itemId);
        return false;
    }

    // 获取 BlockWorld
    auto& blockWorld = GameManager::getInstance()->getBlockWorld();

    // 检查该位置是否可放置
    BlockHandle currentBlock = blockWorld.getBlockAtWorldPos(LayerType::BLOCK, worldPos);
    if (currentBlock.isIDVailed()) {
        CCLOG("Position already has a block");
        return false;
    }

    // 尝试放置方块
    bool success = blockWorld.tryPlaceAtWorldPos(
        worldPos,
        itemData->tileId,  // 物品对应的方块ID
        0,                 // 默认状态
        playerEntity
    );

    if (success) {
        // 消耗背包物品
        Inventory::getInstance()->removeItem(itemId, 1);

        // 播放放置动画
        auto* anim = registry.try_get<PlayerAnimationComponent>(playerEntity);
        if (anim) {
            PlayerAnimationSystem::transitionToState(*anim,
                PlayerAnimationComponent::AnimState::PLACE);
        }

        CCLOG("Placed block %d at (%.2f, %.2f)", itemData->tileId, worldPos.x, worldPos.y);
        return true;
    }

    return false;
}
```

### 4.3 监听方块破坏事件并掉落物品

**文件**: 创建新的监听器类或在现有系统中添加

```cpp
class BlockDropListener {
public:
    static void initialize(entt::dispatcher& dispatcher) {
        // 监听方块破坏事件
        dispatcher.sink<BlockDestroyEvent>().connect<&BlockDropListener::onBlockDestroyed>();
    }

    static void onBlockDestroyed(const BlockDestroyEvent& event) {
        // 根据方块ID决定掉落物品
        int droppedItemId = getDroppedItemFromBlock(event.id);
        int droppedCount = 1;

        // 添加到玩家背包（如果破坏者是玩家）
        auto playerEntity = GameManager::getInstance()->getPlayerEntity();
        if (event.breaker == playerEntity) {
            auto overflow = Inventory::getInstance()->addItemWithOverflow(
                droppedItemId,
                droppedCount
            );

            if (!overflow.empty()) {
                CCLOG("Inventory full! Dropped %d items", overflow.size());
                // TODO: 在世界中生成掉落物实体
            }
        }
    }

private:
    // 方块ID → 掉落物品ID 映射
    static int getDroppedItemFromBlock(entt::id_type blockId) {
        // 示例映射
        static std::unordered_map<entt::id_type, int> blockToItemMap = {
            {1, 2001},   // 泥土方块 → 泥土物品
            {2, 2002},   // 石头方块 → 石头物品
            {3, 3502},   // 原木方块 → 木材物品
        };

        auto it = blockToItemMap.find(blockId);
        return (it != blockToItemMap.end()) ? it->second : 0;
    }
};

// 在游戏初始化时注册监听器
void initializeBlockSystem(entt::dispatcher& dispatcher) {
    BlockDropListener::initialize(dispatcher);
}
```

### 4.4 检测玩家脚下方块（用于地面检测）

**文件**: 在 `PlayerGroundDetectionSystem` 中使用

```cpp
void PlayerGroundDetectionSystem::update(entt::registry& registry, BlockWorld& blockWorld, float dt)
{
    auto view = registry.view<PlayerTag, TransformComponent, PlayerStatsComponent>();

    for (auto entity : view) {
        auto& transform = view.get<TransformComponent>(entity);
        auto& stats = view.get<PlayerStatsComponent>(entity);

        // 检测玩家脚下方块
        cocos2d::Vec2 playerPos(transform.x, transform.y);
        cocos2d::Vec2 feetPos = playerPos - cocos2d::Vec2(0, PLAYER_HEIGHT / 2 + 1);

        BlockHandle blockBelow = blockWorld.getBlockAtWorldPos(LayerType::BLOCK, feetPos);

        // 如果脚下有方块，则视为在地面
        stats.isOnGround = blockBelow.isIDVailed();

        if (stats.isOnGround) {
            stats.currentJumpCount = 0; // 重置跳跃次数
        }
    }
}
```

### 4.5 右键交互方块（打开箱子/工作台）

```cpp
void PlayerInputSystem::handleBlockInteraction(entt::registry& registry, BlockWorld& blockWorld)
{
    auto& input = PlayerInput::getInstance();

    // 检测右键单击
    if (!input.isMouseJustPressed(cocos2d::EventMouse::MouseButton::BUTTON_RIGHT)) {
        return;
    }

    cocos2d::Vec2 mouseWorldPos = input.getMouseWorldPosition();
    auto playerEntity = GameManager::getInstance()->getPlayerEntity();

    // 尝试交互
    bool success = blockWorld.tryInteractAtWorldPos(
        LayerType::BLOCK,
        mouseWorldPos,
        playerEntity
    );

    if (success) {
        CCLOG("Interacted with block at (%.2f, %.2f)", mouseWorldPos.x, mouseWorldPos.y);
    } else {
        // 如果没有交互到方块，则尝试放置方块
        handleBlockPlacement(registry, blockWorld, mouseWorldPos);
    }
}
```

### 5.1 注册事件监听器

```cpp
// 在游戏初始化时
void initializeGame() {
    auto& dispatcher = GameManager::getInstance()->getDispatcher();

    // 监听方块放置事件
    dispatcher.sink<BlockPlacedEvent>().connect<&onBlockPlaced>();

    // 监听方块破坏事件
    dispatcher.sink<BlockDestroyEvent>().connect<&onBlockDestroyed>();

    // 监听方块挖掘事件
    dispatcher.sink<BlockMinedEvent>().connect<&onBlockMined>();

    // 监听方块交互事件
    dispatcher.sink<BlockInteractEvent>().connect<&onBlockInteracted>();
}

void onBlockPlaced(const BlockPlacedEvent& event) {
    CCLOG("Block %d placed at (%d, %d) by entity %u",
          event.id, event.blockPos.x, event.blockPos.y,
          entt::to_integral(event.placer));
}

void onBlockDestroyed(const BlockDestroyEvent& event) {
    CCLOG("Block %d destroyed at (%d, %d) by entity %u",
          event.id, event.blockPos.x, event.blockPos.y,
          entt::to_integral(event.breaker));
```

```cpp
        _blockWorld = std::make_unique<BlockWorld>(_registry, _dispatcher);

    BlockWorld& getBlockWorld() { return *_blockWorld; }
```

### Q6: 如何让工作台检测附近的方块？

**A**: 可以查询玩家周围的方块：

```cpp
void detectNearbyWorkbenches(entt::registry& registry, BlockWorld& blockWorld, entt::entity playerEntity) {
    auto* transform = registry.try_get<TransformComponent>(playerEntity);
    if (!transform) return;

    cocos2d::Vec2 playerPos(transform->x, transform->y);

    // 检测周围5格内的方块
    for (int dx = -5; dx <= 5; dx++) {
        for (int dy = -5; dy <= 5; dy++) {
            cocos2d::Vec2 checkPos = playerPos + cocos2d::Vec2(dx * BLOCK_SIZE, dy * BLOCK_SIZE);
            BlockHandle block = blockWorld.getBlockAtWorldPos(LayerType::BLOCK, checkPos);

            if (block.isIDVailed()) {
                // 检查是否是工作台（假设工作台方块ID为100）
                if (block.id.value() == 100) {
                    StationDetector::getInstance()->addStation(StationType::Workbench);
                }
            }
        }
    }
}
```
