1) 不需要工作站
木材 → 木制平台：1 木材 → 2 平台
木材 → 木制墙：1 木材 → 4 墙
凝胶 → 火把：1 凝胶 + 1 木材 → 3 火把
木材 → 木制箭：1 木材 → 25 木箭（早期非常常见）
2) 工作台（Workbench）高频配方
木材 → 工作台：10 木材 → 1 工作台
木材 → 木门：6 木材 → 1 门
木材 → 木椅：4 木材 → 1 椅
木材 → 木桌：8 木材 → 1 桌
木材 → 木箱（Chest）：8 木材 + 2 铁锭/铅锭 → 1 箱子
木材 → 织布机（Loom）：12 木材 → 1 织布机
(同样的还有相同的类似配方)
这组适合测：同类配方大量存在（不同木头类型往往对应同结构物品）、以及多输入材料（箱子）。
3) 熔炉（Furnace）/矿物冶炼（最核心系统之一）
矿石 → 金属锭（通用规律）
3 铁矿/铅矿 → 1 铁锭/铅锭
4 铜矿/锡矿 → 1 铜锭/锡锭
4 银矿/钨矿 → 1 银锭/钨锭
4 金矿/铂金矿 → 1 金锭/铂金锭
沙块 → 玻璃：2 沙块 → 1 玻璃
石块 → 砖（灰砖）：2 石块 → 1 灰砖（不同版本细节略有差异，但“石→砖”是常见范式）
这组适合测：多种输入映射到同类输出（矿石族）、以及比例不一致（铁系3:1，金系4:1，沙2:1）。
4) 铁砧/铅砧（Anvil）最常见：武器/工具/弹药
铁锭/铅锭 → 铁砧/铅砧：5 铁锭/铅锭 → 1 砧（也用于“工作站递归”）
铁锭/铅锭 → 铁链/铅链：1 锭 → 10 链
铁锭/铅锭 + 木材 → 基础工具/武器（很多是“锭 + 木材”模式；你复现时可以做成数据驱动）
星星 + 箭 → 祝福箭（Jester’s Arrow）：1 堕落之星 + 20 木箭 → 20 祝福箭（典型“弹药升级”）
这组适合测：产出堆叠数量（链、箭类），以及同配方模板、多材料分支（铁/铅等价）。
5) 玻璃窑/家具类（如果你要覆盖更多工作站）
玻璃 + 火把 → 玻璃灯：常见“材料 + 光源”范式（不同版本/物品名可能有差别，但结构很典型
玻璃 → 玻璃墙/玻璃平台：类似木材墙/平台（用于测试“材质替换”的配方族）
6) 炼药桌/瓶子（Alchemy：强烈建议你纳入测试）
泰拉瑞亚合成系统里，“药水”是最典型的：消耗品、多材料、必须站点（放置的瓶子/炼药桌）、产物 1。
治疗药水（基础）：蘑菇 + 凝胶 + 瓶装水 → 治疗药水
魔力药水（基础）：坠落之星 + 凝胶 + 瓶装水 → 魔力药水
瓶装水：水源旁空瓶 → 瓶装水（这条适合测“环境交互/站点判定”，如果你系统还没做环境，就先当成特殊工作站）
