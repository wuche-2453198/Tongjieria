## 项目概述

本项目采用 **ECS架构 + 事件驱动 + 数据驱动** 的设计模式：
- **ECS框架**: EnTT库，组件化管理游戏实体
- **事件系统**: 观察者模式，UI自动响应数据变化
- **数据驱动**: JSON配置，物品和配方完全由数据定义
- **单例管理**: 全局资源统一管理

```cpp
void update(registry, dt) {
    // 水平移动
    processHorizontalMovement(movement, stats, sprite, dt);

    // 跳跃处理
    if (movement.wantsToJump && stats.isOnGround) {
        processJump(movement, stats, sprite);
    }

    // 应用重力和摩擦
    applyPhysics(movement, dt);

    // 同步到Cocos2d物理引擎
    syncPhysics(registry, entity, movement, transform, sprite);
}

void processHorizontalMovement(movement, stats, sprite, dt) {
    if (movement.isMovingLeft) {
        movement.velocity.x -= movement.accelerationRate * dt;
        movement.isFacingRight = false;
    }
    if (movement.isMovingRight) {
        movement.velocity.x += movement.accelerationRate * dt;
        movement.isFacingRight = true;
    }

    // 速度限制
    float maxSpeed = stats.moveSpeed * movement.maxHorizontalSpeed;
    movement.velocity.x = clamp(movement.velocity.x, -maxSpeed, maxSpeed);
}
```

```cpp
    if (animation.currentState != newState) {

    }

    updateFrameAnimation(animation, dt);

AnimState determineAnimationState(movement, stats, sprite) {
    if (stats.isDead) return DEATH;
    if (animation.isUsingItem) return USE_ITEM;
    if (!stats.isOnGround && movement.velocity.y > 0) return JUMP;
    if (!stats.isOnGround && movement.velocity.y < 0) return FALL;
    if (abs(movement.velocity.x) > 1.0f) return WALK;
    return IDLE;
}
```

**核心逻辑 - 添加物品**:

```cpp
bool Inventory::addItem(int id, int count) {
    auto itemData = ItemManager::getInstance()->getItemData(id);
    if (!itemData) return false;

    int maxStack = itemData->maxStack;
    int remaining = count;

    // 1. 先尝试堆叠到现有槽位
    for (auto& slot : _slots) {
        if (slot.itemId == id && slot.count < maxStack) {
            int canAdd = std::min(remaining, maxStack - slot.count);
            slot.count += canAdd;
            remaining -= canAdd;
            if (remaining == 0) break;
        }
    }

    // 2. 放入空槽位
    while (remaining > 0) {
        int emptySlot = getFirstEmptySlot();
        if (emptySlot == -1) return false;  // 背包满

        int toAdd = std::min(remaining, maxStack);
        _slots[emptySlot].itemId = id;
        _slots[emptySlot].count = toAdd;
        remaining -= toAdd;
    }

    dispatchInventoryChanged();
    return true;
}
```

```cpp
bool EquipmentValidator::canEquip(int itemId, EquipSlotType slotType) const {
    // 1. 获取物品装备类型
    EquipType itemEquipType = getEquipType(itemId);
    if (itemEquipType == EquipType::None) return false;

    // 2. 获取槽位期望类型
    EquipType expectedType = slotTypeToEquipType(slotType);

    // 3. 匹配规则
    if (slotType >= EquipSlotType::Accessory0) {

    }

    return typesMatch(itemEquipType, slotType);
}
```

```cpp
std::vector<const RecipeDefinition*> CraftingMatcher::getAvailableRecipes() {
    std::vector<const RecipeDefinition*> result;
    auto* recipeMgr = RecipeManager::getInstance();
    auto& allRecipes = recipeMgr->getAllRecipes();

    // 获取当前工作站
    auto* stationDetector = StationDetector::getInstance();
    auto& currentStations = stationDetector->getCurrentStations();

    // 过滤: 只显示当前工作站可用的配方
    for (auto& recipe : allRecipes) {
        if (currentStations.count(recipe.requiredStation) > 0) {
            result.push_back(&recipe);
        }
    }

    // 排序: 可合成的排在前面
    std::sort(result.begin(), result.end(), [this](auto* a, auto* b) {
        bool canCraftA = canCraft(*a);
        bool canCraftB = canCraft(*b);
        if (canCraftA != canCraftB) return canCraftA;
        return a->recipeId < b->recipeId;
    });

    return result;
}

bool CraftingMatcher::canCraft(const RecipeDefinition& recipe) {
    return checkStation(recipe) && checkMaterials(recipe);
}

bool CraftingMatcher::checkMaterials(const RecipeDefinition& recipe) {
    auto* inv = Inventory::getInstance();

    for (auto& ingredient : recipe.ingredients) {
        if (inv->getItemCount(ingredient.itemId) < ingredient.count) {
            return false;
        }
    }

    return true;
}
```

```cpp
bool CraftingExecutor::craft(const RecipeDefinition& recipe) {
    auto* matcher = CraftingMatcher::getInstance();
    auto* inv = Inventory::getInstance();

    // 1. 验证
    if (!matcher->canCraft(recipe)) {
        return false;
    }

    // 2. 扣除材料
    for (auto& ingredient : recipe.ingredients) {
        bool removed = inv->removeItem(ingredient.itemId, ingredient.count);
        if (!removed) {
            // TODO: 回滚已扣除的材料
            return false;
        }
    }

    // 3. 添加产物
    auto overflow = inv->addItemWithOverflow(recipe.resultItemId, recipe.resultCount);

    // 4. 处理溢出
    if (!overflow.empty()) {
        // TODO: 生成掉落物品实体
    }

    // 5. 事件已由Inventory自动派发
    return true;
}

int CraftingExecutor::craftMax(const RecipeDefinition& recipe) {
    auto* matcher = CraftingMatcher::getInstance();
    int maxCount = matcher->getMaxCraftCount(recipe);

    return craftMultiple(recipe, maxCount);
}
```

### 关键流程示例

**流程1: 玩家装备物品**

```
1. 用户拖拽背包物品到装备槽
   ↓
2. EquipmentPanel::onTouchMoved() 处理拖拽
   ↓
3. PlayerInventoryBridge::equipItem()
   ├─ EquipmentValidator::canEquip() 验证类型
   ├─ Inventory::equipItem() 交换槽位
   └─ PlayerInventoryBridge::calculateEquipmentStats() 重算属性
   ↓
4. Inventory 派发 Event_EquipmentChanged
   ↓
5. EquipmentPanel::refresh() 刷新UI显示
```

**流程2: 合成物品**

```
1. 用户进入熔炉附近
   ↓
2. 游戏检测到熔炉 → StationDetector::addStation(Furnace)
   ↓
3. StationDetector 派发 Event_StationChanged
   ↓
4. CraftBar::onStationChanged() → refreshRecipes()
   ↓
5. CraftingMatcher::getAvailableRecipes()
   ├─ 按工作站过滤 (Hand + Furnace)
   └─ 按材料排序 (可合成的在前)
   ↓
6. UI显示配方列表 (例如: 铜锭配方现在可见)
   ↓
7. 用户点击"合成铜锭"
   ↓
8. CraftingExecutor::craft()
   ├─ removeItem(铜矿, 3)
   ├─ removeItem(煤炭, 1)
   └─ addItem(铜锭, 1)
   ↓
9. Inventory 派发 Event_InventoryChanged
   ↓
10. CraftBar + InventoryLayer 同时刷新UI
```

## 设计模式总结

1. **ECS架构**: EnTT库，组件化设计，系统职责分离
2. **单例模式**: 全局资源管理 (ItemManager, Inventory, RecipeManager等)
3. **工厂模式**: PlayerFactory创建完整玩家实体
4. **观察者模式**: 事件驱动，UI自动响应数据变化
5. **桥接模式**: PlayerInventoryBridge解耦Player和Items系统
6. **数据驱动**: JSON配置，物品/配方完全由数据定义

3. 在对应系统使用新属性
