# Items Resource Directory

此目录包含游戏中所有物品相关的资源文件。

## 目录结构

```
items/
├── bottom/          # UI 底层背景和槽位纹理
├── icons/           # 物品图标（如果有）
└── README.md        # 本说明文件
```

## bottom/ 目录

包含物品栏、装备栏和合成系统使用的 UI 纹理资源。

### 物品槽位背景

| 文件名 | 用途 | 尺寸建议 |
|--------|------|----------|
| `Inventory.png` | 普通物品槽位背景（默认状态） | 64x64 像素 |
| `dark_bottom.png` | 暗色槽位背景（不可用/不可合成状态） | 64x64 像素 |
| `light_bottom.png` | 高亮槽位背景（选中/激活状态） | 64x64 像素 |

### 装备槽位纹理

| 文件名 | 用途 | 装备类型 |
|--------|------|----------|
| `Helmet.png` | 头盔装备槽 | 护甲-头部 |
| `Chestplate.png` | 胸甲装备槽 | 护甲-胸部 |
| `Leggings.png` | 护腿装备槽 | 护甲-腿部 |
| `Accessory.png` | 饰品装备槽 | 饰品（4个槽位） |

### 功能按钮

| 文件名 | 用途 | 位置 |
|--------|------|------|
| `crafting.png` | 合成系统展开按钮 | 屏幕左下角合成栏 |

## 使用说明

### 1. 物品槽位状态
物品槽位根据不同状态使用不同的背景纹理：

- **默认状态**：`Inventory.png` - 普通灰色背景
- **不可用状态**：`dark_bottom.png` - 深色背景（物品不可合成、材料不足等）
- **选中状态**：`light_bottom.png` - 亮色背景（玩家选中该槽位）

### 2. 装备槽位
装备面板右侧显示 7 个装备槽位：
- 3 个护甲槽（头盔、胸甲、护腿）
- 4 个饰品槽

每个槽位使用对应的纹理作为背景提示玩家该槽位的用途。

### 3. 合成系统
合成系统分为两部分：
- **垂直配方列表**（左侧）：显示所有可用配方，每个配方使用 `Inventory.png`、`dark_bottom.png` 或 `light_bottom.png` 作为背景
- **快速合成栏**（屏幕中心）：横向排列可合成物品的图标，使用相同的背景纹理系统

## 交互逻辑

### 合成系统交互
1. **不可合成的物品**：显示 `dark_bottom.png` 背景，点击无效
2. **可合成的物品**：
   - 第一次点击：背景变为 `light_bottom.png`（高亮选中）
   - 第二次点击：执行合成操作，合成后重置状态

这种两次点击设计防止玩家误操作，提供更好的用户体验。

## 资源要求

### 图片格式
- 推荐使用 PNG 格式（支持透明通道）
- 建议使用 32 位色深（RGBA）

### 尺寸规范
- 物品槽位：64x64 像素
- 装备槽位：64x64 像素
- 功能按钮：根据设计需求（建议 48x48 或 64x64）

### 命名规范
- 使用英文命名，避免使用中文或特殊字符
- 使用下划线或驼峰命名法
- 保持命名的一致性和可读性

## 相关代码文件

- `Classes/items/InventoryLayer.cpp` - 物品栏 UI 实现
- `Classes/items/EquipmentPanel.cpp` - 装备栏 UI 实现
- `Classes/items/CraftBar.cpp` - 合成系统 UI 实现
- `Classes/items/ItemManager.cpp` - 物品数据管理

## 注意事项

1. **纹理加载路径**：代码中使用相对路径 `items/bottom/xxx.png`，确保文件放置在正确位置
2. **缺失纹理处理**：如果纹理加载失败，系统会使用默认颜色填充或回退方案
3. **性能考虑**：避免使用过大的纹理文件，建议压缩优化
4. **设计一致性**：所有槽位背景应保持统一的视觉风格
